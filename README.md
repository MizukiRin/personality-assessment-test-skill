# 人格认知测评与心智建模专家 Skill (Personality Assessment Test)

这是一个基于严肃**分析心理学（荣格八维动力学 / 毕比原型心智模型）**与**现代动态九型人格系统（三中心、27种副型序列、三元组防御阶梯）**的深度人格测评与心智建模 Agent Skill。

---

## 核心设计特性

1. **双轨制交互架构（Dual-Track Protocol）**：
   - **前台对话（纯自然倾听与共情）**：对话彻底脱离学术说教与生硬的理论归因标题（拒绝 `### 【理论归因】`），全程如同资深心理咨询师般温和、敏锐、不设防地交流，营造安全松弛的倾诉氛围。
   - **后台档案（学术级线索追踪）**：在交互过程中，LLM 在后台动态创建并实时追加维护 `outputs/clue_tracking_dossier.md`，精密记录每一轮的探针意图、言语线索捕获、认知功能/九型归因与交叉排他验证过程。
2. **长程递进式深度探索（12~18+ 轮交互）**：
   - 彻底摒弃机械式、选择题式静态题库；
   - 采用多轮螺旋收敛机制，从冷启动了解受测者的现实生活语境开始，层层递进探入潜意识心智底层。
3. **动态情境嫁接（Dynamic Scenario Weaving）**：
   - 将心理学学术测量目标（不变量）与用户的真实生活坐标（可变量：如不同职业、学生、家庭结构等）动态结合；
   - 实时生成贴合用户现实、具备真实摩擦力的高张力两难生活切片，诱导潜意识第一直觉体感自然浮现。
4. **抗歧义出题与动机消歧机制（Disambiguated Motive-Driven Probing）**：
   - **表象与动机严格分离**：受测者的同一个词句（如“有很多可能的分叉”、“做事有计划”），背后可能对应截然相反的心理动力（如：是对可能性的兴奋探索，还是因未来不确定而焦虑抓瞎）。严禁按字面粗暴贴标签；
   - **禁绝抽象哲学隐喻**：彻底废除“未来是清晰还是分叉”等文学空想隐喻，将问题深度锚定在真实场景的“生理感受与情绪底色（充能 vs 耗能，跃跃欲试 vs 悬空焦虑）”；
   - **即时语义澄清机制**：对宽泛或多义回答，Agent 会自然追问一层深层动机，彻底杜绝人机理解错位。
5. **八维 × 九型复合动力学与跨型号对比**：
   - 深入分析当前荣格八维 + 九型人格组合的典型行为特质与思维定式；
   - 重点对比“同一套 MBTI 八维在搭载不同九型主型号时”的显著差异与外显风貌；
   - 提供该复合心智架构的天然擅长领域、最佳工作协作模式与心智跃升指引。
6. **现代极简编辑美学与双模报告交付**：
   - 同时支持生成纯文本 Markdown 深度档案与自包含的流式 HTML 交互大屏；
   - **现代低饱和美学**：采用温暖纸质质感底色（`#FAF9F5`）、1px 极简细线、现代无衬线字体，告别生硬的 Tab 切换，采用优雅舒适的自上而下顺序长卷阅读；
   - **LLM 原生矢量线条艺术（SVG Watermark）**：由大模型根据用户的精神气质现场动态构思并手写专属矢量几何线条艺术与精神锚点金句，作为氛围水印优雅融入报告背景。

## 使用与运行流程

作为 Antigravity / Claude Agent Skill 使用：
1. **启动测试**：当用户提出性格测评、深度八维探索或心智分析需求时，Agent 会自动载入 [`SKILL.md`](./SKILL.md)，以专业咨询师身份开启多轮自然对话探索。
2. **前台对话**：像资深心理咨询师一样保持温和、敏锐、自然的倾听与共情，不向受测者抛出晦涩难懂的学术理论或生硬的格式标签。
3. **后台更新**：在会话推进过程中，实时同步更新 `outputs/clue_tracking_dossier.md`，记录理论证据链。
4. **生成报告**：测评结束后调用子 Skill 及脚本，交付双模报告（Markdown 深度档案与极简长卷 HTML 报告）。
